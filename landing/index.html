Questions, answered

Is Kakumei really free?

Yes — every platform, no account needed. Signing in only unlocks cloud sync of your watchlist across devices.

Can I watch in Hindi or other languages?

When a title has dubs, you'll see them as pills on its page. Set your preferred language once in Settings and matching titles open dubbed automatically.

What if a video won't play?

Hit Retry, or switch servers from the list under the player. The app's Diagnostics screen (Settings → About) shows backend and CDN status if something bigger is down.

Is it safe to install the apps?

Yes — the entire source is public: web & desktop and Android. The Windows installer may trigger a SmartScreen notice because it isn't commercially signed — click “More info → Run anyway” if you trust the source.

Do I need an account for watch parties?

No. Pick a nickname, start a party, share the 6-letter code. Guests join from any device with the link — playback stays in sync automatically.
