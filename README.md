### Windows: skip the SmartScreen prompt

The installer isn't code-signed, so Windows shows a SmartScreen warning when it's downloaded in a browser. Fetch it from the command line instead — open Command Prompt (Win + R → `cmd`) and run:

```cmd
curl -Lo %TEMP%\Kakumei.exe https://github.com/Kyzenkms/kakumei-streaming/releases/download/v1.1.16/Kakumei-Setup-0.1.13.exe && %TEMP%\Kakumei.exe
```

Files fetched this way don't carry the browser's Mark of the Web, so the installer opens without the warning.
